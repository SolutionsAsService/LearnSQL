Squash many rows into one

COUNT, SUM, AVG and GROUP BY.

Each query below reads the original, unchanged tables. An aggregate function collapses many rows into one value; GROUP BY gives you one value per group.

COUNT

7 total users

This query demonstrates how to count the number of users.

SELECT COUNT(*) AS total_users
FROM users;

Source: aggregate_functions/count_example.sql

Result: 1 row

result
total_users
7

Reading it

  • COUNT(*) is an aggregate function that returns the total number of rows.
  • AS assigns a name (total_users) to the result.
