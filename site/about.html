About

A small, honest SQL primer. The only claims it makes are ones the build checks.

How the numbers get here

python3 _src/build.py reads the eleven .sql files in the repository folders, runs each in SQLite against _src/data/seed.sql, and writes every table and figure on this site from what came back. The build stops if a printed figure changes or a link breaks.

What is not covered

SQLite is not every database. RIGHT JOIN and FULL OUTER JOIN need SQLite 3.39 or newer, and MySQL has no FULL OUTER JOIN. The data is invented: nobody in it is real.

Contribute

Add a .sql file with a leading comment and an -- Explanation: block, list it in _src/build.py, and rebuild. See CONTRIBUTING.md.

Every result on this site was produced by running the query in SQLite 3.53.1, on invented data. Source on GitHub. By SolutionsAsService.
